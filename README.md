# twitch.lua — плагин Twitch для VLC

**Русский** | [English](README_ENG.md)

Скрипт плейлиста для VLC, который открывает прямые трансляции и записи (VOD) Twitch прямо в VLC.

Он заменяет стандартный `twitch.lua`, поставляемый с VLC 3.0. Стандартный скрипт обращается к удалённым эндпоинтам `api.twitch.tv/api/*` и Kraken, а они теперь отвечают HTTP 410. Эта версия повторяет схему веб-плеера Twitch: сначала GQL-запрос `PlaybackAccessToken`, затем мастер-плейлист HLS с `usher.ttvnw.net`.

## Возможности

- Воспроизводит трансляции и VOD анонимно. Вход в аккаунт, OAuth-токен и Client-Integrity не нужны.
- Делает один GQL-запрос на открытие: он возвращает сразу и токен доступа, и метаданные (название, имя канала, категорию, статус трансляции).
- Заполняет метаданные VLC: *Название*, *Исполнитель*, *Жанр*, *Сейчас играет* и *Описание*.
- Пишет понятные ошибки в журнал VLC, если канал не найден, трансляция не идёт или токен отклонён (например, из-за геоблокировки).
- Сразу стартует на лучшем качестве. Скрипт пропускает вариант только со звуком и использует `adaptive-logic=highest`, поэтому нет разгона с 160p, перезапуска демуксера и пересинхронизации PCR после старта.
- Работает на Windows, Linux и macOS.

## Поддерживаемые ссылки

| Ссылка | Что открывается |
|---|---|
| `https://www.twitch.tv/<канал>` | Трансляция |
| `https://twitch.tv/<канал>` | Трансляция |
| `https://m.twitch.tv/<канал>` | Трансляция |
| `https://go.twitch.tv/<канал>` | Трансляция |
| `https://www.twitch.tv/videos/<id>` | VOD |

Клипы (`clips.twitch.tv`) не поддерживаются и намеренно не распознаются.

## Требования

- VLC 3.0.x.
- `curl` в `PATH`. Lua API VLC умеет отправлять только GET-запросы и без своих заголовков, поэтому GQL-запрос методом POST уходит через системный `curl`.

| ОС | curl |
|---|---|
| Windows 10 1803+ / 11 | Встроен (`C:\Windows\System32\curl.exe`) |
| macOS | Встроен (`/usr/bin/curl`) |
| Linux (пакет дистрибутива) | Обычно уже установлен. Если нет — `sudo apt install curl` или аналог для вашего дистрибутива |
| Linux (Flatpak / Snap) | VLC использует curl из своей песочницы, а там его может не быть. См. [Диагностику](#диагностика) |

## Установка

Скопируйте `twitch.lua` в пользовательскую папку скриптов плейлиста, создав её при необходимости:

| ОС | Путь |
|---|---|
| Windows | `%APPDATA%\vlc\lua\playlist\` |
| Linux | `~/.local/share/vlc/lua/playlist/` |
| Linux (Flatpak) | `~/.var/app/org.videolan.VLC/data/vlc/lua/playlist/` |
| Linux (Snap) | `~/snap/vlc/current/.local/share/vlc/lua/playlist/` |
| macOS | `~/Library/Application Support/org.videolan.vlc/lua/playlist/` |

VLC загружает пользовательские скрипты раньше встроенных, поэтому этот файл автоматически заменяет встроенный `twitch.luac`. После установки перезапустите VLC.

## Использование

- **Интерфейс:** *Медиа → Открыть URL* (`Ctrl+N`), вставьте ссылку на канал или VOD.
- **Командная строка:**
  ```sh
  vlc https://www.twitch.tv/<канал>
  vlc https://www.twitch.tv/videos/<id>
  ```

## Настройка

Параметры воспроизведения задаются в таблице `OPTIONS` в начале скрипта:

```lua
local OPTIONS = { ":adaptive-logic=highest" }
```

| Значение | Поведение |
|---|---|
| `:adaptive-logic=highest` | По умолчанию. Лучший вариант с первого сегмента, качество никогда не снижается |
| `:adaptive-logic=nearoptimal` | Подстраивается под скорость канала. Лучше для нестабильного интернета, но может стартовать с более низкого качества |
| `:adaptive-logic=highest`, `:adaptive-maxheight=720` | Лучший вариант, но не выше 720p |

Эти параметры действуют только на элементы, созданные скриптом. Глобальные настройки VLC не меняются.

## Как это работает

1. `probe()` проверяет, что ссылка ведёт на twitch.tv.
2. `parse()` извлекает из ссылки логин канала или id VOD.
3. `gql()` отправляет через `curl` один POST на `https://gql.twitch.tv/gql` с публичным веб-`Client-ID`. Запрашивается:
   - для трансляции: `streamPlaybackAccessToken` и `user { displayName stream broadcastSettings }`;
   - для VOD: `videoPlaybackAccessToken` и `video { title description owner game }`.
4. Скрипт собирает URL usher из `value` и `signature` токена:
   - трансляция: `https://usher.ttvnw.net/api/channel/hls/<login>.m3u8?...`
   - VOD: `https://usher.ttvnw.net/vod/<id>.m3u8?...`
5. Возвращается элемент плейлиста с метаданными. Дальше HLS-поток воспроизводит демуксер `adaptive` VLC.

В теле запроса нет строковых литералов, обратных слэшей и переводов строк: все значения передаются как переменные GraphQL. Поэтому одна функция экранирования безопасно работает и для `cmd.exe`, и для `sh`, без временных файлов.

## Диагностика

Откройте *Инструменты → Сообщения* в VLC или запустите `vlc -vv` и найдите строки, начинающиеся с `Twitch:`.

| Сообщение в журнале | Что значит / что делать |
|---|---|
| `bad GQL response: empty (is curl installed?)` | `curl` не найден или ничего не вернул. Установите curl или проверьте, что он есть в `PATH` |
| `GQL error: ...` | Twitch отклонил запрос. Возможно, изменился API — создайте issue |
| `channel not found: <name>` | Логин написан с ошибкой, либо канал забанен или удалён |
| `<name> is offline` | Канал сейчас не ведёт трансляцию |
| `playback forbidden: <code>` | В токене отказано, например из-за геоблокировки |
| `no access token for video <id>` | VOD не существует или не публичный |

**Flatpak / Snap:** проверьте, виден ли curl внутри песочницы:

```sh
flatpak run --command=sh org.videolan.VLC -c 'command -v curl'
snap run --shell vlc -c 'command -v curl'
```

Если команда ничего не вывела, используйте VLC из пакета дистрибутива.

## Известные ограничения

- **Мелькание консоли на Windows.** `io.popen` запускает `cmd.exe`, поэтому при каждом открытии ссылки Twitch на мгновение появляется окно консоли. Это ограничение Lua-песочницы VLC.
- **Загрузка HTML до запуска скрипта.** VLC скачивает HTML-страницу twitch.tv (~200 КБ) ещё до вызова `probe()`. Скрипты плейлиста работают как фильтры потока поверх уже открытого URL, поэтому этого не избежать.
- **Реклама.** У анонимных токенов `server_ads: true`, поэтому Twitch может вставлять рекламные сегменты в поток.
- **Контент только для подписчиков.** Такие VOD и трансляции требуют авторизованного токена, который скрипт не поддерживает.
